# WP-006 inactive upstream comparison boundary

The user authorized autonomous implementation/review/merge of port PRs.
This package implements source comparison and owner-routed **proposal data**;
it does not use that authorization to advance
`db14559b39d32322b06477c6ae676112f583db50`, create upstream/fork issues, enable
a schedule, edit live gate identities, or approve a reference/ownership change.
The manifest's human reference-advance gate and existing off/paused policy
remain intact.

The source pin supplies both blob ownership and exclusion provenance.
Unknown added inputs and renamed destination mappings block automatic routing
acceptance. Existing owner/consumer proposals retain complete evidence,
including source tests/resources, deleted files and current Android consumers.
Native generated-source headers are included, not just direct `PortedFrom`
lines. Mode-only changes are retained even when source bytes did not change.

Deduplication is by immutable source delta plus WP. A new candidate commit with
the same delta or a newly added Android implementation does not spawn another
proposal. Prior proposal files are not authoritative issue/review/lease receipts:
every repeated change stays in the report, with a visibility flag only.

No issue is automatically created: the app's native issue tool is the supported
creation path after the user chooses a reviewed proposal. Full artifact-backed
proposal contents are not squeezed into a 65,535-byte status or silently paged
through an unapproved publisher. The helper emits summaries only and requires
complete private output for changed sources.

Path-scoped PR checks exercise Windows/Linux fixtures without upstream access.
Actual upstream comparison is manually dispatched with an explicit commit
and trusted default-branch controller code; no candidate code is executed.
The manual comparison's intentionally skipped PR job is not a missing test
suite. No unmodified-source refresh, protected acceptance, legal/hardware
certification or full Android feature parity is inferred from this automation.
