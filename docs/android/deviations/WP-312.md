# WP-312 deviations and protected boundary

## Provider integration is not admitted

WP-312 is not wholly marked as a human-gated work package, so provider-neutral
domain, lifecycle, snapshot-cache and offline-region seams are implemented.
However, ADR-002 says that neither a map engine nor any base, satellite or
topographic provider is approved by name. Engine permission is also separate
from style, font, sprite, tile, attribution, caching, quota, key, offline and
snapshot redistribution rights.

The Android implementation therefore does not link MapLibre or another map SDK,
embed provider URLs or terms, request a permission, download a tile, render a
decorative fake map or claim native 16 KiB compatibility. The map feature keeps
the existing explicit unavailable state. `MapProviderCatalog`,
`MapLayerDescriptor`, `SharedMapAdapter`, `OfflineMapBackend` and
`MapSnapshotRenderer` are injection boundaries for a later approved adapter.

## Native adaptations completed

- Core Location/MapKit coordinates and regions are immutable validated Kotlin
  values with source-equivalent camera persistence, bounding and distance rules.
- Map point, line, clustering, filter, appearance and focus values are
  provider-neutral and preserve source defaults and filtering invariants.
- Snapshot caching is generic over the provider image type. It preserves rounded
  keys, offline-dark collapsing, in-flight de-duplication, serial rendering,
  multicast resolution notifications, bounded FIFO success/failure state,
  retry, clear and cancellation.
- Offline-region policy validates disk, network, layer admission and zoom before
  delegating to a backend. Cancellation propagates and no success is fabricated.

## Remaining protected work

Completion remains blocked on a human decision covering the exact engine and
each provider/style/resource, attribution presentation, network/cache/offline
terms, download retention/deletion, quotas/keys and snapshot redistribution.
After admission, WP-312 still requires the real adapter, interactive map UI,
offline database behavior, provider-backed tests, native 16 KiB evidence and
the remaining owned source/test-family accounting.
