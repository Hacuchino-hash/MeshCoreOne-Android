## Interfaces and type mirrors

Feature modules may not depend on `core:services`. The holders reach services only
through feature-owned ports, which WP-303 must adapt. For the maintainer, these are the
type-placement decisions:

- `CliToolFeatureDependencies`: live providers, each read where it's used, so a null read
  means disconnected (Swift `CLIToolViewModel.Dependencies`). It wraps these ports:
  - `CliRepeaterAdminPort.sendRawCommand(EntityKey, command, timeout)` for `RepeaterAdminService`.
  - `CliRemoteNodePort` (createSession/login/logout/retrieve/store/deletePassword) for the
    `RemoteNodeService` slice. `login` returns `LoginResult.success` as a `Boolean`.
  - `CliSettingsPort`: the 14 `SettingsService` methods, with signatures identical to
    `core/services/.../SettingsService.kt` on main, so the adapter is plain delegation.
    Failures stay `SettingsServiceException` (`core:contracts`). The `can't find custom var`
    branch matches `SessionError(MeshCoreException.DeviceError)` with `ILLEGAL_ARGUMENT`.
  - `CliNodeDirectory`: `fetchContacts`/`fetchChannels`, narrowed from `ContactPersisting`/`ChannelPersisting`.
- `NodeCliSender`: the node CLI's `sendRawCommand(command, timeout)` closure.
- `RadioStatsSource.getStatsRadio(): RadioStats` (the `core:protocol` type) for the `MeshCoreSession` slice.
- `RxLogFeed` (`loadExistingEntries`/`entryStream`/`clearEntries`, matching WP-212's
  `RxLogService` on `mine/wp212-diagnostics`), `RxLogContactSource`, `RxLogFeatureDependencies`.
- **Mirrors.** `CliRemoteFault` (Timeout, PasswordNotFound, LoginFailed, Cancelled) mirrors
  the `RemoteNodeError` cases the terminals branch on. `CliErrorPresentation.remoteFault`
  classifies them, and after WP-210 merges WP-303 can map from `RemoteNodeFault`. `CliTimeouts`
  mirrors `RemoteOperationTimeoutPolicy.defaultCLITimeout` (10 s) and `fireAndForgetCLI` (2 s).
  `CliErrorPresentation.describe` stands in for `localizedDescription`; it defaults to `message`.
- `DiagnosticsText`: resource-id strings (`ResourcesDiagnosticsText` wraps `Resources` and
  `android.icu.text.ListFormatter`). Formatted keys go through `FormattedStringIds`, because the
  generated accessors need `Resources`. `DiagnosticsClock`: injected `now()`/`sleep()`.

## Adaptations

- **A-01 Swift text semantics.** These are explicit, not JVM defaults: `CharacterSet.whitespaces`
  (which includes U+200B), per-scalar `lowercased()` with no final sigma, `split` with
  maxSplits/empties, the `Double(String)` grammar (hex, `inf`/`nan`, rejects `1.0f`),
  ASCII-only `Int`/`UInt8` (accepts `-0`), and NFC Unicode-scalar `sorted()`.
  `String(format:"%.Nf")` uses the exact binary value rounded half-even, with `-0`/`nan`/`inf`.
  `.rounded()` rounds ties away from zero. Foundation's `fractionLength(1)` rounds the shortest
  decimal half-even. `localizedCaseInsensitiveCompare` uses `java.text.Collator` at SECONDARY
  strength. Every value was printed by `swiftc` (`docs/android/evidence/WP-316/oracle*.swift.txt`).
  Known residue: on the JDK the Collator ignores space and hyphen when *ordering* (ICU does not).
  Android's Collator is ICU-backed. Equality matched on all oracle pairs.
- **A-02 State holders.** These are plain classes, not `@Observable` view models: an immutable
  `StateFlow` state, an injected `CoroutineScope` (which must be single-threaded, matching
  `@MainActor`) and an injected clock. An androidx `ViewModel` can wrap each one. Swift
  test-only `var` writes (`activeSession`, `currentInput`, `isPolling`) are setter methods or
  are driven through start/stop.
- **A-03 Cancellation.** `CancellationException` is always rethrown, never swallowed. The busy
  flag is claimed synchronously. A `LAZY` job is registered before it starts, so an immediate
  dispatcher cannot strand the flag. Only the current job may clear the flag. One visible
  difference: Swift's remote `reboot` path would print the description of a `CancellationError`;
  Kotlin prints nothing.
- **A-04 Line ids.** `CliOutputLine.id` is a per-terminal `Long` counter rather than a `UUID`.
  Local `CliSession`s still get fresh UUIDs, and remote ones carry the `EntityKey`.
- **A-05 Cursor/clipboard.** Cursor offsets are UTF-16 (`TextFieldValue.selection`) rather than
  Swift `Character` counts, and they never split a surrogate pair. Ghost-text suffixes still drop
  graphemes. The UI reads the clipboard and passes the text in. The SwiftUI `onChange`
  side effects (ghost refresh, tab clear) are reproduced in the controller.
- **A-06 Presentation models.** Chart domain, axis ticks and labels, trend, accessibility text,
  row path/labels/details and raw hex are computed in Kotlin. The x-axis ticks are multiples of 60
  inside the domain, which approximates Swift Charts `.stride(by: 60)`. SF Symbol names are kept as
  `NoiseFloorQuality.sourceSymbol` tokens for the UI to map. Deferred to the UI pass: colors, the
  locale skeleton date (`.dateTime.month(.twoDigits)...`), SNR bars/quality (`SNRQuality` isn't on
  this classpath), pulse/glass styling, haptics and the copied-checkmark timer.
- **A-07 Service fakes.** The Swift local-command tests drive the real `SettingsService` over a
  mock session. `core:services` isn't on this module's test classpath, so `FakeSettings`
  reproduces the service contract: verified read-back, `VerificationFailed`, and the
  `SessionError(DeviceError)` wrap. These 41 cases are tagged `adapted-service-fake`, and so is
  the node-CLI reboot-timeout case, which classifies a fake timeout through `CliErrorPresentation`.
